READ BEFORE USING

This is not the full-baseline forecast.

Only T1 and TA1 are available. T2 / TA2 (same-venue head-to-head) and T3 / TA3 (two-meeting head-to-head average) are unavailable for this newcomer track. These current-form-only values are directional and must not be compared directly with forecasts on the Full Baseline Dashboard.

Forecast inputs: current top-flight T1 / TA1 form and current-season player totals come from Understat.

Prior context only: second-tier match history comes from Football-Data.co.uk. It is shown for context, is never used in a forecast, and its raw CSV files are not exposed by this page.

Coverage: 11 actual newcomers across the tracked leagues; France contributes two.
